## 📁 Содержание репозитория

### 1. [System maintenance.md](System%20maintenance.md)
Справочник по обслуживанию системы. Включает основные команды для поддержания стабильности и чистоты ОС (работа с кэшем пакетов, обновление системы и оптимизация базы данных pacman).

### 2. [Helpful instructions Manjaro.md](Helpful%20instructions%20Manjaro.md)
Сборник прикладных решений для повседневных задач:
*   Настройка **автоматического монтирования** второго диска (fstab).
*   Оптимизация производительности в играх (настройка FPS в Steam).
*   Конфигурация системных параметров под личные нужды.

### 3. [Flatpak.md](Flatpak.md)
Шпаргалка по использованию универсального менеджера пакетов Flatpak: основные команды установки, удаления и обновления приложений в изолированном окружении.

## 🛠 Инструментарий
В качестве основной среды разработки и работы с текстом я использую **Code - OSS** — версию Visual Studio Code с открытым исходным кодом из официальных репозиториев Manjaro. Это позволяет сохранять систему «чистой» и минимизировать использование проприетарного софта.
